# Optimo hybrid prototype review

This branch contains the actual revised HTML prototype and design notes.

## Open the prototype

1. Download `Optimo-hybrid-review.zip` from this branch.
2. Extract the ZIP.
3. Open `Optimo-hybrid/optimo-full-hybrid.html` in a current Chrome, Edge, Firefox or Safari browser.

The HTML includes both complete source prototypes, the common workspace, and the added guidance. No server, installation, internet connection, or original-file selection is required. GitHub displays HTML as source; download and open it locally to interact.

## Included

- `review/optimo-full-hybrid.html`: revised full workflow workspace.
- `review/design-decisions.md`: design rationale and integration boundary.
- `review/v53-v56-feature-inventory.md`: event/resource capability inventory.
- `review/r7-feature-inventory.md`: facility/planning capability inventory.

The workspace preserves the full V53/V56 workflows and r7 facility/planning capabilities. The reference datasets remain separate, and some source endpoints are simulations; this is an interaction prototype rather than a live booking system.
